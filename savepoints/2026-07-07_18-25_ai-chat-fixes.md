## Decisions made
- **Subscriptions in AI spending**: subs live in `SubscriptionManager.subscriptions` (persisted UserDefaults `cashmonki_subscriptions`), not in `currentUser.transactions`; only `autoAddTransaction` ones materialize as Txns. Project the rest into spending. Cap at `now` (matches real-txn semantics), skip days already covered by a real `subscriptionId`-linked txn (no double-count), expenses only. Raw `sub.amount` (no FX convert) to match how auto-add txns store amount. Future periods intentionally show no subs.
- **@MainActor fix**: SubscriptionManager is `@MainActor`, AskChatService is a plain class. Added `nonisolated static func persistedSubscriptions()` reading the UserDefaults store instead of touching the isolated property. (UserManager + CategoriesManager are plain ObservableObject → fine to call.)
- **Live markdown**: per-word flow layout can't do cross-word bold. Switched streaming view to a single `Text(AskFormat.markdown(...))` off the growing text. Trade-off accepted: lost the per-word opacity fade.
- **Limit bubble**: not a gate bug (gate math correct). The "You've used today's free messages" notice was appended AND persisted; immortal thread re-rendered it after the daily reset. Made it ephemeral (never persisted) + strip existing ones on load.
- **JSON leak**: model produced MIXED output (prose then a redundant, truncated `{"type":"text",...,"choices":[...]}`). Leading prose latched the stream to plain-text so the JSON tail streamed raw; truncated JSON failed `extractJSONObject`, so decode showed raw. Fixed at 3 layers (decoder strip + stream guard + prompt).
- **Chip clip**: chips already in a horizontal ScrollView but clipped by the list's `.padding(.horizontal, 20)`. Full-bleed: content inset 20 + ScrollView `.padding(.horizontal, -20)`.
- **Greeting**: `👋 How's it going {name}` → `👋 Hey {name}`.
