## Runtime bugs found and fixed this session
1. **Raw JSON dumped into chat.** `AskTransactionDraft.type` was non-optional, but entries nested in
   a `transaction_draft_batch` carry no `"type"` (the envelope has it) → decode threw → fallback
   printed the envelope. `type` is now `String?`.
2. **Anti-leak net.** Any known message type failing validation now returns a friendly line and logs
   `🔴 AskMessageDecoder: unrenderable reply` to console. Unknown envelope types too. Raw JSON can
   no longer reach the chat.
3. **Category lost on revision.** "change to 100" made the model emit a bare draft with no
   `suggested_categories` → transaction landed in No Category. Fixed BOTH sides: prompt demands the
   full proposal including suggested_categories, AND `appendPending` inherits suggestions from the
   card being replaced (draft→draft, batch→batch by row index, batch→single matched by merchant then
   amount). Merchant inherits the same way.
4. **"Replaced by the updated suggestion below." removed** (user disliked it). Superseded cards now
   drop out of the UI *and* the model's history via `AskChatManager.visibleMessages` — leaving them
   described as PENDING told the model two proposals were live.
5. **Batch card bottom padding** now 8 (matching the rows' side inset) when the Add all button is
   absent, 16 when present.
