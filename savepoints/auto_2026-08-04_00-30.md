## What runtime testing found (the payoff)
Running the app in the simulator found a bug no amount of code reading had:
```
💾 UserManager: Session restored from LOCAL STORAGE
☁️ UserManager: User explicitly disabled sync - leaving OFF   ← while Settings showed "Backed up · 1hr ago"
```
`loadFromFirebase` copied the CLOUD `enableFirebaseSync` into the local box, so a stale `true`
overwrote a local opt-out; the UserDefaults key the launch path obeys still said false. Fixed in
`4750edb7`: the cloud no longer overwrites a per-device preference, and `reconcileSyncPreference()`
heals already-drifted devices.

## Fixed this session (all build-verified, mostly NOT device-verified)
- `a29d5625` **launch pulls before pushing**. STEP 1 (`UserManager.swift:181`) loaded the local box
  and returned, so the sign-in restore in STEP 2 never ran on a device with a box — and it PUSHED
  first, letting a stale local `accounts` array overwrite the cloud's. Failed pull now skips the
  user-doc push entirely.
- `ef889592` **no new empty wallet on Gmail login**. Placeholders identified by ID (every generated
  default is recorded), never by name — real wallets are called "<Name>'s Wallet" too.
- `29fb950c` wallet deletions propagate (graveyard in `UserData.deletedAccounts`); cloud default
  wallet wins the `isDefault` election.
- `4a975439` subscriptions sync edits AND deletes (was union = additions only). `updatedAt` +
  `isDeleted` on the model, hand-written decoder, tombstones in a private graveyard.
- `bc82cf15` no duplicate subscription occurrence on first sign-in (`hasGeneratedOccurrence`).
- `6ae08aa8` shared transaction tombstones at `users/<uid>/meta/deletions` + 5th listener.
- `8903c913` **linked boxes are display-only**. The previous version copied the account's bytes over
  the box on every save — that could overwrite ANOTHER account's box (the picker lists them) and
  measured 575 KB × N per save against a 6.4 MB plist.
- `ace5a242` restore unions wallet tombstones; placeholder-drop is cloud-merge-only; snapshots
  pruned to newest 3; Firestore tombstone doc capped at 5000 ids.
- `705935c7` + `d0063e87` Restore from a save file, merged with upload into one "Local save files"
  row (verb chosen per file: Add = union, Restore = replace).
- `52c07079` + `fb9a31e8` Download cloud data (reads Firestore directly, named after the account,
  green cloud disk art).
- `87bdaa4a` Delete cloud data; `deleteAllUserData` no longer orphans `categories`/`subscriptions`/

- `9697f424` + `7db45299` signed-in email under the profile name, 4pt gap.
