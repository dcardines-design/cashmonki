## Technique notes
- `print()` never reaches the unified log: `xcrun simctl terminate … && xcrun simctl launch --console-pty … > /tmp/log 2>&1` (backgrounded; `timeout` not installed).
- Xcode 16 puts app code in `CashMonki.debug.dylib`, not the thin binary — `strings` on the executable falsely looks stale.
- Never run `xcodebuild` while Xcode builds: both lock the same DerivedData build database ("error: accessing build database").
- ASC/Firebase forms are React — set values via the native setter + `input`/`change` events, not `el.value =`.
- ASC blocks navigation with a "Leave site?" dialog when a field is unsaved.
