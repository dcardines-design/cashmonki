# What's New — 3.7.0 (12)

Paste into App Store Connect → 3.7.0 → What's New in This Version.

---

Ask got a lot more capable this update.

• Log several transactions in one message. Say "add 300 groceries, 150 milk and 90 bread" and Ask lays them out as a list you can add one by one, or all at once. Tap any of them first if you want to change something.

• Set up and manage budgets from the chat. Create one, change the limit, pause it for a while, or remove it. Ask shows you exactly what will change before anything is saved.

• Handle recurring payments and subscriptions the same way. Start tracking Netflix or rent, update the amount when a price goes up, move the due date, stop it from auto adding, or pause it.

• Change your mind mid-conversation. Say "make it 150" or "that's food, not coffee" and the suggestion in front of you updates, instead of you having to start the request over.

• The Ask box now shows examples of what you can say, so the things it can do are easier to find.

Fixes

• Signing out and back in no longer creates an extra wallet each time.

• The wallet you have selected is remembered between launches and after app updates.

• Fixed a case where an assistant reply could show up as unreadable text.
